# 학교 마커 설계 (프론트)

작성일 2026-11-02 · 상태: 사용자 승인 2026-11-03 · main(경매 #113, 로드뷰 모드 #114 포함) 위에서 구현

## 의도

집을 고를 때 근처 학교가 어디인지 지도에서 바로 보이게 한다. 백엔드 #51·#52가 부산 학교(나이스 `schoolInfo`, 부산교육청 C10 소속 전부) 점 데이터와 `GET /schools` API를 만들었다.

예전 브레인스토밍 E안의 "학원가 영역"은 이번에 하지 않는다. 데이터가 학원이 아니라 학교이고, 사용자가 "묶어서 표시하지 말고 경매처럼 낱개로" 정했다. 병원은 이번에 하지 않는다(사용자 결정).

## 목표

1. 줌 14 이상에서 지도 화면 안의 학교를 낱개 마커로 보여준다.
2. 초·중·고·특수·기타를 색, 글자, 도형으로 구분한다.
3. 레이어 버튼에서 학교 표시를 켜고 끈다.
4. 학교 마커를 누르면 학교 정보 시트가 열린다.

## 하지 않는 것

- 병원 표시, `/nearby` 주변 학교 요약(단지 시트 안)
- 학군·배정 학교 판단. 데이터가 없다. API 안내문 `meta.school_notice`를 그대로 보여준다.
- 학교 군집 영역, 학교끼리 묶은 숫자 마커

## 이렇게 되면 실패다

- 도형이 마커 칸 밖으로 튀어나오거나 칸 테두리에 딱 붙는다. 사용자가 "딱 맞아도 안 되고 살짝 마진이 있으면 좋음"이라고 했다.
- 학교 마커 때문에 실거래 가격이나 경매 마커가 가려진다.
- "가까운 학교"를 "배정 학교"처럼 보이게 쓴다.

## API (백엔드 main 909df9b 기준)

`GET /schools?bbox=min_lng,min_lat,max_lng,max_lat&level=elementary,middle,high,special,other`

- 화면 안 최대 500개, 페이지 없음. `level`을 생략하면 전부 준다.
- 항목(`SchoolOut`): `id`, `name`, `kind`, `level`(elementary|middle|high|special|other), `foundation`(공립·사립 등), `coed`(남녀공학 등), `address`, `lat`, `lng`, `tel`, `homepage`, `opened_on`, `distance_m`(bbox 조회에서는 null)
- `meta`: `data_as_of`, `source_attribution`(배열, `["나이스 교육정보 개방 포털", "건강보험심사평가원"]`), `school_notice`("배정 학교(학군)가 아니라 직선거리로 가까운 학교입니다")
- 배포 서버에 아직 없으면 404, 수집 전이면 503 `DATA_NOT_READY`다. 둘 다 학교 마커를 조용히 생략하고, 레이어를 켠 상태면 지도 위 안내 한 줄("학교 정보를 준비 중이에요")을 띄운다.

## 정한 것

### 1. 마커 모양 (사용자 승인 B안, 시안 `school-markers-v3.html`)

- 흰 바탕 칸이다. 높이 26px, 테두리 1.5px는 레벨 색, 모서리 반경 9px, 그림자는 기존 마커와 같다. 왼쪽 안쪽 여백 3px, 오른쪽 8px.
- 칸 왼쪽에 **20×20px 배지 자리**가 있고, 그 가운데 도형이 놓인다. 도형은 칸 테두리 안쪽에서 **사방 최소 2px** 떨어진다(시안 실측 2.3~5px).

| 레벨       | 색      | 도형                            | 크기  | 글자 |
| ---------- | ------- | ------------------------------- | ----- | ---- |
| elementary | #D08A00 | 동그라미                        | 18×18 | 초   |
| middle     | #1F8A87 | 네모(반경 3px)                  | 16×16 | 중   |
| high       | #5B3FA0 | 마름모(45° 회전 네모, 반경 2px) | 13×13 | 고   |
| special    | #6B6B66 | 네모(반경 3px)                  | 16×16 | 특   |
| other      | #6B6B66 | 동그라미                        | 18×18 | 기   |

- 마름모의 글자는 다시 -45° 돌려 똑바로 세운다.
- 도형 안 글자는 흰색 굵게 10px(마름모 9.5px)이다.
- 칸 오른쪽에는 줄인 학교 이름을 11px 굵게 쓴다. 줄이는 규칙: 끝의 "초등학교"→"초", "중학교"→"중", "고등학교"→"고", "여자"→"여"(예: "해운대여자고등학교"→"해운대여고"). 앞의 "부산"은 지우지 않는다. 시트에는 원래 이름을 쓴다.
- 꼬리(아래 삼각형)는 없다. 학교 좌표에 **도형 배지 가운데**(칸 왼쪽에서 14.5px)를 맞춘다. 칸 가운데를 맞추면 배지가 좌표 왼쪽으로 밀려 학교 옆에 뜬 것처럼 보인다.
- 다른 마커와 겹치면 점으로 줄이지 않고 **이름 없는 작은 배지**(칸 안에 학교급 도형만)로 그린다. 점이면 매매 화면처럼 가격 마커가 많을 때 학교인지 알아볼 수 없어서다. 작은 배지는 가운데를 좌표에 두고, 가격 마커 위(zIndex 11)에 그려 가려지지 않게 한다. 겹침 판정 자리는 차지하지 않는다. 누르면 확대하지 않고 시트를 연다(경매 점과 같다).
- 범례: 학교 레이어가 켜져 있고 줌 14 이상일 때 지도 왼쪽 아래(출처 표기 위)에 "● 초 ■ 중 ◆ 고 ■ 특수"를 작게 띄운다. 기타는 화면 안에 있을 때만 범례에 더한다. _(내 판단)_

### 2. 겹침 우선순위

선택 > 지역 > 실거래 > 경매 > 학교 순이다. 학교가 가격과 경매를 가리지 않는다. 학교끼리는 고 > 중 > 초 > 특수 > 기타 순으로 자리를 잡는다. _(내 판단: 큰 학교가 먼저)_

- rank 값: 실거래 2 이상 3 미만, 경매 3 이상 4 미만, 학교 5 이상(고 5, 중 5.1, 초 5.2, 특수 5.3, 기타 5.4)이다.
- 런타임은 지금 "attach 없는 마커 → attach 있는 마커(단지 옆 경매)" 순으로 자리를 잡는다. 학교는 **attach 경매보다도 뒤에** 처리해서, 단지 옆 경매를 점으로 밀어내지 않게 한다.
- 선택한 학교 마커는 색을 검정으로 바꾸지 않는다. 레벨 색을 그대로 두고 rank 0과 높은 z-index만 준다.

### 3. 켜고 끄기

- 기존 레이어 시트(배경 지도·지적도 스위치가 있는 곳)에 "학교" 스위치를 더한다.
- **처음 기본값은 꺼짐이다.** 지적도 스위치와 같은 방식으로 저장한다. App에서 `loadStored("schools", false)`로 불러오고 `store("schools", on)`으로 저장하므로, 한 번 켜면 앱을 다시 열어도 켜진 채로 남는다. _(내 판단: 처음 화면은 덜 어지럽게, 켠 사람은 계속 보게)_
- 줌 14 미만에서 켜져 있으면 "확대하면 학교가 보여요" 안내를 띄우지 않는다. 범례만 숨긴다. _(내 판단: 경매 탭처럼 주인공 데이터가 아니라서)_
- 매매·전세·월세·경매 어느 탭에서도 켤 수 있다. 토지 탭에서도 켤 수 있다.

### 4. 요청

- 조건은 학교 켜짐, 부산 안(`!outside`), `camera.zoom >= 14`다. 실거래 요청과 같은 220ms 디바운스와 AbortController 취소를 쓴다.
- 쿼리는 `bbox`뿐이다. `level`은 보내지 않고 다 받는다.
- 응답 `lat`/`lng`가 null인 학교는 그리지 않는다.

### 5. 학교 시트

- 경매·단지 시트와 같은 `Sheet`를 쓴다. 학교 정보가 짧아서 peek 하나로 다 보이게 하고, 위로 올려도 같은 내용이다.
- 내용:
  - 칩: 레벨 이름("초등학교"·"중학교"·"고등학교"·"특수학교"·"기타 학교", 레벨 색), 설립 구분(`foundation`), 남녀공학(`coed`)
  - 제목: `name` 원래 이름
  - 주소: `address`에서 "부산광역시 "를 뺀 값
  - 전화: `tel`, 누르면 전화 걸기(`tel:`). 웹에서는 글자만 보여준다.
  - 홈페이지: `homepage`, "홈페이지 열기 ↗"
  - 개교일: `opened_on`이 있으면 "YYYY.MM.DD 개교"
  - 안내 박스: `meta.school_notice`. 없으면 "배정 학교(학군)가 아니라 직선거리로 가까운 학교입니다"를 쓴다.
  - 출처: "출처: 나이스 교육정보 개방 포털 · 기준일 {data_as_of}". 학교 시트에는 학교 출처만 쓴다.
- 데이터는 목록 응답에 있는 값을 그대로 쓴다. 상세 API는 없고 따로 부르지 않는다.

### 6. 데이터 계층

- `src/api/types.ts`: `SchoolLevel`, `School`, `Meta`에 `school_notice?: string`을 더한다. `source_attribution`은 경매에서 `string`으로 들어갔으므로 `string | string[]`로 넓히고, 이를 문자열로 쓰는 `AuctionContent` 등도 함께 맞춘다. 학교 응답의 `meta`는 `onMeta`(앱 전체 기준일)로 넘기지 않고 학교 시트에서만 쓴다.
- `Repository.schools(bbox: BBox, signal?: AbortSignal): Promise<Envelope<School[]>>`
- 샘플 모드: `fixtures.ts`에 학교 5곳을 넣는다(초 2, 중 1, 고 1, 특수 1). 우동·센텀 근처에 두고 bbox로 거른다.

### 7. 지도 연결

- `MapProps.schools?: School[]`
- `src/map/markers.ts`의 `schoolItems(schools, selected)`가 `MarkerItem`을 만든다.
  - `MarkerItem`에 `school?: SchoolLevel`을 더한다.
  - 마커 id는 `school:{id}`다.
  - 글자 필드는 `amount`에 줄인 이름, `title`·`sub`는 빈 값이다.
- 런타임(`kakaoRuntime.ts`):
  - `.pg-marker.school` 변형 클래스로 위 1절의 모양을 CSS로 그린다.
  - 레벨별 도형 클래스는 `lv-elementary` 등이다.
  - 앵커는 세로 가운데(`yAnchor: 0.5`), 가로는 배지 가운데(`xAnchor: 14.5 / 칸 너비`)다. 충돌 사각형도 같은 기준으로 잡는다. 작은 배지가 된 학교는 가운데 정렬이다.
  - 작은 학교 배지의 onclick은 경매 점처럼 확대하지 않고 `marker` 이벤트를 보낸다.
  - 도형 여백(사방 2px 이상)은 jsdom으로 잴 수 없다. 웹 미리보기에서 눈과 `getBoundingClientRect`로 확인한다.
- "학교 정보를 준비 중이에요" 안내는 경매 안내와 같은 자리(`top 24%`)에 겹치지 않게 둔다.
- MapHome: `school:` 접두어를 누르면 `selected = { kind: "school", school }`로 학교 시트를 연다.

- 범례 컴포넌트의 정확한 위치(출처 표기와 겹치지 않게)
- 레이어 시트 안 스위치 순서와 문구 다듬기
- 테스트 구성(TDD, vitest + testing-library, 경매 작업의 테스트 방식을 따름)
