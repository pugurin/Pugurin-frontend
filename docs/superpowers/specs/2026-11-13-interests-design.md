# 관심 단지·지역 등록 설계 (#140)

## 왜
로그인(#137) 다음 기능. 기능명세 F-INT-01(관심 단지), F-INT-02(관심 지역, 법정동 최대 10개)를 앱에서 쓸 수 있게 한다.
백엔드가 다른 일로 바빠서 지금은 목데이터로 동작하고, API 명세 §10 모양에 맞춰 나중에 서버로 바꿔 끼운다.

## 목표 / 비목표
- 목표: 단지·지역 ☆ 등록/해제, 더보기의 관심 목록, 로그인 안 한 사람 안내
- 비목표: 새 거래 알림(F-NOTI-03, 서버 배치), 매물 찜(3차), 실제 서버 연결
- 실패로 볼 것: 로그아웃·다른 계정에서 남의 관심 목록이 보이는 것, 같은 항목이 두 번 들어가는 것

## 접근
- **선택: 인증과 같은 구조.** `InterestsApi` 인터페이스 + 앱 안 가짜 서버 `SampleInterests`. 로그인 토큰이 필요한 기능이라 인증 쪽 구조(`src/api/auth.ts`)를 따른다.
- 버린 안: `Repository`의 sample 모드에 넣기. Repository는 토큰 없는 공개 조회용이라 섞으면 서버 연결 때 다시 떼어내야 한다.

## 설계
- `src/api/interests.ts`
  - `InterestsApi`: `addComplex/removeComplex/listComplexes`, `addRegion/removeRegion/listRegions` (세션을 받는다)
  - `SampleInterests`: 키 `sample_interests.<user_id>`로 기기에 저장. 등록은 멱등. 지역 10개 초과는 `ApiError`("관심 지역은 10개까지예요"). 단지 목록에는 목 거래 중 그 단지의 최신 거래를 붙인다. 탈퇴하면 그 사용자 목록을 지운다.
- 로그인 안 했을 때 ☆: "로그인하면 관심 등록할 수 있어요" 토스트 + 로그인 화면
- 단지 시트 ☆: 등록되면 채운 별(강조색), 토스트 "관심 단지에 담았어요"/"관심 단지에서 뺐어요"
- 지역 시트 ☆: 동 단위에서만 보인다(명세가 법정동 기준). 시·군·구는 숨김
- 관심 목록 화면(더보기 → 관심 목록): 탭 `단지 n | 지역 n/10`. 단지를 누르면 지도로 이동해 단지 시트를 연다(기존 `openComplex`). 지역을 누르면 그 동으로 지도를 옮긴다(검색에서 지역을 고를 때와 같다. 지역 시트는 마커를 눌러 연다 — 빌더 판단). ★로 해제. 빈 상태 "지도에서 ☆를 눌러 담아 보세요"
- ☆ 상태는 `InterestsContext`로 내려 준다(시트까지 props를 여러 단계 넘기지 않으려고. `LearningContext`와 같은 방식)

## 빌더에게 맡김
목록 행 세부 레이아웃, 지도 이동 줌 수준, 아이콘 모양(기존 `star` 아이콘 재사용)
