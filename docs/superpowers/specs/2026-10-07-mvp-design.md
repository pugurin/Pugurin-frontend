# 프론트엔드 1차 화면 구현 기준

사용자가 확정한 Real Estate Wireframes v2.dc.html을 구현한다. 6번 토지 시트·상세(S07 전체)는 제외한다. 01/01-1 지도 홈, 04 레이어, 05 필터, S04 검색, S05 지역, S06 단지 3단계, S08 거래 목록, 08 용어사전, 02 더보기, 03 기준일, 13 약관을 포함한다. 2차 기능은 자리 안내만 제공한다.

기존 Expo + React Native + TypeScript를 본 앱으로 이어간다. 지도는 카카오 JavaScript SDK를 웹에서는 직접, 네이티브에서는 WebView 브리지로 연결한다. VWorld·MapLibre는 본 앱 의존성에 포함하지 않는다. 카카오 JavaScript 키·등록된 웹 도메인은 환경변수로 주입한다. 키가 없으면 명시적으로 샘플 지도 모드로 실행한다.

시안의 360px 모바일 구성, 종이색 배경(#FAFAF7), 먹색 텍스트(#111110), 아파트 파랑(#3E64A0), 오피스텔 보라(#7B5A9E), 빌라 장미(#B0506B), 토지 초록(#4F7A3A)을 유지한다. 본문 16px, 터치 영역 48px 기준. 면적 평/㎡, 가격 원 단위 수신, 공급/전용 구분, 거래 취소 표시를 지킨다.

API 모드와 샘플 모드는 명시적으로 구분한다. 실제 모드는 /api/v1 계약을 사용하고 디바이스 ID, ETag/304, 오류, 로딩, 빈 결과, 마지막 요청 반영을 처리한다. 통계 계산은 API/샘플 어댑터에서 제공하며 화면에서 재계산하지 않는다. 최근 검색어 및 면적/레이어 설정은 기기에 저장한다. 토지 주소 선택 시 제외된 상세로 이동하지 않고 안내한다.

실 광고 SDK 및 법적 약관 원문은 제공되지 않았으므로 광고 슬롯과 약관 미제공 상태로 표시한다. 카카오 키 없는 상태에서 실지도 검증, 실제 API에 없는 엔드포인트 검증은 완료 주장하지 않는다.

사용자 추가 결정: 백엔드 API를 추가하지 않는다. 메인83fe44d에서 제공되는 API만 연결하며 지역 거래목록·통계·분석은 준비 상태로 제공한다.
