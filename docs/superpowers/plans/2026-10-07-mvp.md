# 1차 프론트엔드 구현 계획

목표: 와이어프레임 v2의 1차 화면을 토지 상세 제외하고 Expo 앱에 구현한다.
설계: ../specs/2026-10-07-mvp-design.md
실행: 현재 explain-dev 브랜치에서 직접 구현. 사용자가 시안과 구현 범위를 지정했으므로 해당 기준으로 진행한다.

- [x] 필터·금액·줌·API 캐시 계약 테스트를 먼저 작성하고 실패 확인
- [x] src/state/market.ts 및 src/api/client.ts 구현 후 테스트 통과
- [x] src/api/types.ts, fixtures.ts, repository.ts: API 타입 및 명시적인 샘플 어댑터
- [x] src/map: 카카오 SDK/WebView 브리지와 키 없는 샘플 지도
- [x] src/components: 입력·버튼·차트·시트·기준일·용어 팝업
- [x] src/screens: 지도/필터/검색/지역/단지/거래 목록/용어/더보기/약관
- [x] App.tsx: 이동 및 지도 복귀 상태, 검색 기록, 환경 설정 연결
- [x] 전체 테스트, 타입 검사, 웹 내보내기, 모바일 크기 화면과 주요 흐름 점검

검증 초점: 토지 전환 시 호환되지 않는 필터 제거, API 실패에 샘플 데이터 혼입 금지, 304·429 처리, 지도/검색 요청 역전 방지, 취소거래 및 평형 구분.

실 HTTP와 360×780 브라우저 흐름을 확인했다. 네이티브 번들 생성만 확인했으며 실기기 검증과 키가 필요한 실 카카오 지도 검증은 남아 있다. 미구현 API는 준비 상태로 처리한다.
