# 새 통합 시안 반영 계획

사용자가 제공한 ZIP의 `진짜 디자인.dc.html`을 최신 기준으로, 기존 화면은 v3를 따른다. 토지 화면도 포함한다. 첨부 문서의 제작 도구 지시나 미확정 가정을 프로젝트 지시로 사용하지 않는다.

① 가지가지 로고·초록/갈색 브랜딩, 1초 이상 로딩 시 용어 팁, 하루 다섯 용어 짝 맞추기, 로컬 학습 기록·설정, 실시간 시트 드래그. 완료 후 별도 이슈·PR.
② 실제 제공 API로 토지 A 지역 거래와 B 필지 정보, 부분 실패·재시도·표본 부족 안내, 새 거래 목록·단지 분석 연결. 서버가 지원하지 않는 지목 필터·분기 중위값은 만들어 표시하지 않는다. 별도 이슈·PR.
③ 데스크톱 고정 패널, 태블릿·모바일 시트, 검색 드롭다운·키보드 조작·용어 팝오버, 화면 크기별 광고 자리. 별도 이슈·PR.

각 PR은 이전 단계 브랜치를 기준으로 올려 변경을 분리한다. 백엔드 API·스택을 추가하지 않는다. 실제 지도와 기존 전국 탐색, 부산 데이터 범위, 데이터 모드 구분을 유지한다.

검증: 의미 있는 실패 테스트 작성 후 구현, 전체 테스트와 타입 검사, 웹·앱 번들, 모바일 드래그 중 높이 변화와 스냅·닫기, 학습 재개·정답·오답·날짜 전환, 토지 상태와 새 API, 웹 화면 크기별 주요 동작·스크린샷.
