# 경매·공매 물건 표시 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 매매 지도와 새 "경매" 탭에서 경매·공매 물건을 마커, 3단계 시트, 단지 시트 카드, 목록 화면으로 보여준다.

**구조:**

- 경매는 실거래 `Filters`에 섞지 않는다. App이 따로 `auction: boolean` 상태를 들고 MapHome에 넘긴다. `queryForFilters`가 `Filters`의 모든 키를 쿼리로 보내기 때문이다.
- 데이터는 `Repository.auctions`와 `Repository.auction`으로 받는다.
- 화면 문구 계산은 순수 함수 모듈 `src/state/auction.ts`에 모은다.
- 지도에는 `MarkerItem`에 경매 변형을 더해 카카오 런타임으로 넘긴다.

**기술 스택:** Expo + React Native(Web) + TypeScript, 카카오맵 JS SDK 런타임(`src/map/kakaoRuntime.ts`), vitest + @testing-library/react

**설계 문서:** `docs/superpowers/specs/2026-11-02-auction-design.md`. 실행자는 이 계획과 설계 문서를 둘 다 읽는다.

## 전역 제약

- 문구·주석은 한국어로 쓴다. 비밀값은 커밋하지 않는다.
- 통계·필터는 API 결과를 쓴다. 프론트에서 거르거나 정렬하지 않는다. 예외는 화면 문구용 한 줄 계산(`1 - min_price / recent_trade_price`)뿐이다.
- 감정가 기준 값은 항상 **"감정가의 N%"**로 쓴다. "N% 할인"이나 "-N%"는 감정가 기준으로 쓰지 않는다.
- 실거래 비교 필드(`recent_trade_price`, `recent_trade_date`, `recent_trade_area_m2`, `recent_trade_count`)와 쿼리 `sort`, `exclude_share`는 **아직 서버에 없다.** 필드는 선택값으로 받고, 없거나 null이면 해당 UI를 숨긴다. 서버가 쿼리를 지원하는지는 응답 `meta.sort`가 있는지로 판단하지 않는다. 대신 상수 `AUCTION_SERVER_SORT = false` 하나로 정렬 칩과 지분 칩을 숨기고, 서버가 지원하면 이 값만 true로 바꾼다.
- 경매 API가 404 또는 503 `DATA_NOT_READY`이면 지도 마커와 단지 카드는 조용히 생략한다. 경매 탭에서만 "경매 정보를 준비 중이에요"를 띄운다. 샘플로 대체하지 않는다.
- 경매 마커는 `camera.zoom >= 14`(서버 `zoom_complex_min`과 같은 값, 상수 `AUCTION_MIN_ZOOM = 14`)에서만 요청하고 그린다.
- 색: 경매 테두리·글자는 `C.brown`(#B02A22), 실거래 비교 줄은 `C.greenInk`(#2f7a2c), 지분 칩은 `#FFF3D6` 바탕에 `#8A5E08` 글자.
- 출처는 `meta.source_attribution`, 원문 링크는 `meta.source_url`을 그대로 쓴다.
- 작업 브랜치는 `feat/auctions`이고 main에서 딴다.

## 리뷰 초점

테스트가 직접 다루지 않지만 실제 사용자가 만날 가능성이 큰 입력이다. 각 줄의 테스트는 해당 작업에 넣었다.

1. **가격 빈 값:** `min_price`나 `appraisal_price`가 null이다. 마커는 "최저가 미정"이 되고, "감정가의 N%" 줄은 숨긴다. 문구에 NaN이나 "null"이 나오면 안 된다. (작업 2)
2. **좌표 없음:** `lat`/`lng`가 null이면 지도에서 빠지고 목록에만 나온다. 런타임에 NaN 좌표를 넘기면 안 된다. (작업 3)
3. **최저가가 실거래보다 비쌈:** 비교 줄은 "최근 실거래보다 N% 높아요"가 되고 초록색을 쓰지 않는다. (작업 2)
4. **끝났거나 지난 기일:** `is_closed=true`이거나 기일이 오늘보다 앞서면 D-day 칩을 숨긴다. 끝난 것은 "끝난 경매" 칩을 쓴다. (작업 2)
5. **빠른 지도 이동:** 지도를 빠르게 움직이면 이전 경매 요청을 취소한다. 늦게 온 응답이 새 화면의 마커를 덮으면 안 된다. (작업 4)
