4명세에 없지만 필요하다고 판단한 것
  1. 마커 겹침 처리 — 거래가 많은 마커부터 그리고 겹치면 점으로 줄여요. 점을 누르면 한 단계 확대. 명세에 규칙이 없어요.
  2. 선택된 마커 상태 — 선택하면 진한 색 + 맨 위. 시트를 닫으면 선택도 풀려요.
  3. 줌 단계 기준 — 프로토타입은 줌 12 미만 구, 12~14 동, 14 이상 단지로 가정했어요 (정책 #4 미정).
  4. 토지 모드 진입 동작 — 토지를 고르면 지적도 자동 켜기 + 안내 토스트. 매번 띄울지, 처음 한 번만 띄울지 정해야 해요.
  5. 빈 땅 누르기 범위 — 토지 모드에서만 땅을 고를 수 있게 했어요. 아파트 등 다른 모드에서 빈 지도를 누르면 시트만 닫혀요. 줌 14 아래에선 “조금 더 확대해 주세요” 안내.
  6. 기간 칩 동작 — 기간 칩을 누르면 기간만 고르는 작은 시트(3·6·12·24·36·60개월). 가격·면적·직거래는 전체 필터에서.
  7. 위치 권한 사전 안내 — OS 권한 창 전에 앱 안내 화면을 둬요. 거부하면 부산시청 주변에서 시작.
  8. 부산 밖 판단 — 지도 가운데가 부산 범위를 벗어나면 마커 요청을 멈추고 배너. 돌아가기는 처음 위치로.
  9. 로딩 표시 기준 — 300ms가 넘을 때만 “불러오는 중” 표시. 그동안 이전 마커는 흐리게 유지.
  10. 전세·월세 단지 마커의 계약월 — W3 표대로 전세·월세 단지 마커에는 계약월을 뺐어요. F-MAP-01은 “계약일 표시”라서 맞출지 확인이 필요해요.
  11. 전세 구·동 마커 길이 — “평당 보증금 1,800만”은 마커가 넓어져 겹침이 늘어요. 줄임말을 쓸지 정해야 해요.
  12. 하단 시트와 광고 — 시트가 올라오면 광고 배너는 시트 뒤로 가려져요. 광고 노출 기준과 맞는지 확인이 필요해요.
  13. 용어 팝업 → 용어사전 이동 — 용어사전 탭으로 넘어가고, 뒤로 가면 원래 지도와 시트로 돌아와요.
  14. 용어 검색 결과 없음 — 자주 찾는 용어를 대신 보여줘요. 검색어 저장은 하지 않아요.
  15. 지도 레이어 설정 저장 — 일반/위성, 지적도 켜기를 기기에 저장할지 정해야 해요.
