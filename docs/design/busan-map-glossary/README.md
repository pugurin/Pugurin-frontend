# Handoff: 부산 실거래가 지도 — 지도 홈 + 용어사전

## Overview
부산 16개 구·군 전용 부동산 실거래가 지도 앱(Expo 기반 모바일 앱)의 **지도 홈**과 **용어사전** 화면 디자인입니다.
- 타겟: 40~50대 실구매자(토지·건물 매매 중심, 전세·월세도 지원)
- 앱을 열면 바로 지도. 지도 위 실거래가 마커 → 구·동·단지·필지 요약 시트 → 어려운 용어는 (?) 팝업과 용어사전으로 해설
- 기준 문서: 기능명세서 v1.1, API 명세서 v0.4
- 범위 밖: 검색 화면, 단지 상세, 토지 상세, 로그인·관심·채팅(2차), 매물(3차). 이 화면들은 진입점만 있습니다.
- 금지: 가격 예측·투자 권유 문구("오를 것", "사세요")

## About the Design Files
이 폴더의 파일은 **HTML로 만든 디자인 참고 자료**입니다. 보이는 모습과 동작을 보여주는 프로토타입이며, 그대로 배포할 프로덕션 코드가 아닙니다.
할 일은 이 디자인을 **대상 코드베이스의 기존 환경(Expo / React Native)과 그 패턴·라이브러리로 다시 구현**하는 것입니다. 코드베이스가 아직 없으면 Expo(React Native + TypeScript)로 시작하는 것을 권장합니다.
- `.dc.html` 파일은 브라우저에서 바로 열립니다(같은 폴더의 `support.js` 필요). 로컬 파일로 열면 `fetch`/`import`가 막히므로 **간단한 정적 서버로 여세요**: `npx serve .` 후 `http://localhost:3000/Map%20Prototype.dc.html`
- 배경 지도(`busan-map-mock.svg`)는 **실제 앱에서 지도 SDK(카카오맵 또는 네이버지도)가 그리는 부분**입니다. 구현 대상은 그 위에 올라가는 요소(마커, 플로팅 버튼, 시트, 칩, 탭, 토스트)입니다.

## Fidelity
- **하이파이(hifi)**: `Map Glossary Board.dc.html`의 "3 · 하이파이 시안 · B안" 섹션과 `Map Prototype.dc.html`. 최종 색, 글자, 간격, 동작입니다. 정확히 재현하세요.
- **로파이(lofi)**: 같은 보드의 "1 · 와이어프레임" 섹션(회색조). 레이아웃·흐름 참고용입니다.
- 색 방향은 **B안 확정**: 차분한 중립(종이색 배경, 먹색 버튼) + 초록·갈색은 토지 관련 요소에만. A안은 비교용으로만 남아 있습니다.

## 공통 규칙 (40~50대 기준)
- 화면 기준 360×780 (iOS·Android 공통)
- 본문 16px 이상, 마커 금액 16px Bold(최소 15px), 보조 정보는 14px(마커 보조는 13px)
- 터치 영역 48px 이상 (칩은 높이 44px + 위아래 여백으로 48px 확보)
- 숫자 표기: 1억 이상 `14.5억`(소수 1자리, .0 생략), 1억 미만 `9,800만`, 월세 `5,000/80`(만 원 단위), 계약월 `'26.08`, 날짜 `2026.08.14`
- 면적: 공급 평형이 있으면 `34평`, 없으면 `전용 25.7평`. 1평 = 3.3058㎡, 소수 1자리
- 예시 데이터는 모두 부산 지명

### 6. 용어사전 (W7)
**목록**
- 제목 "용어사전" 26px Bold (padding 12/18/6)
- 검색 입력: 높이 52, radius 12, 기본 테두리 1px `#DCDCD5`, 포커스·입력 중 2px `#111110`, 지우기 버튼(28px 원, `#B8B8B0`)
- 분류 칩: 전체 / 거래 / 토지 / 건물 / 세금 (높이 42, radius 21, 16px). 선택 = `#1F1E1B` 채움, 토지 선택 = `#4F7A3A` 채움, 토지 기본 = 초록 테두리·글자
- 검색어 없음 + 전체: "자주 찾는 용어" 칩(높이 44, radius 12, 16px SemiBold) → 8px 구분 띠 → "전체 용어"
- 목록 행: 용어 18px Bold + 분류 13px SemiBold(토지는 `#4F7A3A`) / 한 줄 설명 15px `#5A5A55`, 오른쪽 › 아이콘. 행 사이 1px `#DCDCD5`
- 정렬: `display_order` → 가나다순
- 검색 결과 없음: "‘양도세’에 맞는 용어가 없어요" 19 Bold + "띄어쓰기를 바꾸거나 다른 말로 검색해 보세요" + "이런 용어는 어떠세요" 자주 찾는 용어 칩

**상세**
- 뒤로가기(48×48) + "용어 목록" 또는 "지도로 돌아가기"(팝업에서 왔을 때)
- 분류 배지, 용어 30px Bold, 한 줄 설명 카드(18px SemiBold, 흰 배경, 테두리), "쉽게 풀면" + 자세한 설명 17px/1.7, "예시"
- 예시 그림: 용적률 = 땅 100평 위 5층(층당 50평) 쌓기 그림 + "= 연면적 250평, 250평 ÷ 100평 = 250%". 건폐율 = 땅 사각형 안에 건물 60평 + 마당 40평. 나머지 용어는 예시 문장만(배경 `#F2F2EE` 상자)

**용어 팝업 (공통 컴포넌트)**
- 화면 어디서든 (?)를 누르면 뜸. 배경 dim `rgba(17,17,16,.45)`
- 카드: left/right 20, radius 18, padding 20. 용어 22 Bold + 분류 배지, 한 줄 설명 18px/1.6, [닫기](흰색) [용어사전에서 보기](먹색, 폭 1.7배)

## Interactions & Behavior
- 지도: 드래그 이동, 핀치·휠 확대/축소(포인터 위치 기준), +/− 버튼은 정수 줌 단위로 260ms 애니메이션
- 화면 이동 애니메이션: 360~700ms, ease-out cubic (`1 - (1-t)^3`)
- 지도가 멈추고 220ms 뒤 마커 재요청(debounce). 요청 순서가 바뀌면 마지막 요청만 반영
- 유형·거래·기간을 바꾸면 기존 마커를 지우고 즉시 재요청
- 시트: 손잡이(또는 헤더)를 위로 40px 이상 끌면 절반, 아래로 50px 이상 끌면 한 단계 내림(살짝에서는 닫힘), 짧게 누르면 살짝 ↔ 절반 전환. 높이 전환 220ms `cubic-bezier(0.2,0.7,0.2,1)`
- 빈 지도를 누르면: 토지 모드 → 필지 조회, 그 외 → 시트 닫기
- 기간 칩: 기간만 고르는 작은 시트(3·6·12·24·36·60개월, 3열 그리드, 버튼 높이 52). 가격·면적·직거래 제외는 전체 필터(다음 작업)
- 토스트: 검정 `#1F1E1B`, radius 12, 16px, 2.6초(토지 안내는 4초)
- 내 위치: 파란 점(22px, `#3E64A0`, 흰 테두리 4px, 바깥 링 8px `rgba(62,100,160,.2)`)

## State Management
지도 화면 상태:
- `view`: `{ cx, cy, zoom }` (실제 앱은 SDK 카메라 상태)
- `filters`: `{ property_type: 'apartment'|'officetel'|'villa'|'land', deal_type: 'sale'|'jeonse'|'monthly', period_months: 1~60 (기본 12) }`. land면 deal_type은 sale 고정
- `markers`, `level`, `loading`, `error`, `outOfBusan`
- `selectedId`, `sheet: { type: 'region'|'complex'|'parcel', data } | null`, `sheetState: 'peek'|'half'`
- `parcelHighlight` (필지 geometry), `layer: { base: 'normal'|'satellite', cadastral: boolean }`
- `permission: 'ask'|'granted'|'denied'`, `toast`
용어사전 상태: `q`, `category`, `view: 'list'|'detail'`, `termId`, `returnTo`, `popupTermId`

데이터 요청 (API 명세서 v0.4):
- `GET /map/markers?bbox=&zoom=&property_type=&deal_type=&period_months=` → `data.level`(sigungu/dong/complex), `data.markers[]`(`kind`: region/complex/parcel, `summary`, `latest`), `meta.data_as_of`, `meta.reporting_lag_notice`
- `GET /complexes/{id}` (최근 거래 3건 포함)
- `GET /parcels/lookup?lat=&lng=` → `zonings[]`, `restrictions[]`, `geometry`, `glossary`
- `GET /glossary?q=&category=` → `term`, `category`(trade/land/building/tax), `is_popular`, `display_order`, `short_definition`, `long_definition`, `example`
- 전세·월세의 구·동 `summary` 필드명(`median_deposit_per_pyeong`, `median_deposit`, `median_monthly_rent`)은 가짜 API에서 가정한 이름입니다. 실제 명세와 맞춰 주세요.
